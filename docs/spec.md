# 青空猫 仕様

設計の議論（2026-10-18）で確定した内容。元アプリとの違いを確かめた記録は [original-app.md](original-app.md) にある。用語の定義は [CONTEXT.md](../CONTEXT.md)、縦書きの描画方式は [ADR-0001](adr/0001-webview-vertical-rendering.md) を参照。

## 目的と前提

- 配信停止した「青空読書」(me.hatasei.bunko) の代わりに、自分で使うアプリを作る。使用感は元アプリに寄せる。
- ソースは GitHub で公開する。元アプリのコードは流用しない。
- Kotlin + Jetpack Compose。minSdk 31、targetSdk は最新。
- 配布は GitHub Actions で署名済み APK を作り、Releases に置く。`v*` タグの push でビルドする。署名鍵は GitHub Secrets に置く。

## データ

- カタログは青空文庫公式の作品一覧 CSV（`list_person_all_extended_utf8.zip`）から作り、端末内の DB に入れる。初回起動時にダウンロードし、以後は手動の更新ボタンで取り直す。自動更新はしない。
- 作品を開いた時点で、XHTML と挿絵を端末に自動保存する。本棚への追加とは関係しない。
- ランキングは公式の 2022 年通年（XHTML 版）を固定で使う。年月の切り替えは作らない。
- 作品詳細の「作品について」と作家詳細の「人物について」は CSV にないので、詳細画面を開いたときに図書カード・作家ページの HTML から取り出して保存する。
- 分野の第 3 次区分（例: 913 小説・物語）の名前は、元アプリからは写さず、公開されている NDC の資料から作る。
- 元アプリからのデータ移行はしない。バックアップは Android 標準の自動バックアップに任せる。

## 画面（下部 4 タブ）

1. **ホーム**：上部に検索バー（作家名・作品名。読みでも引ける）。新着作品とランキングを数件ずつ表示し、「もっと見る」で全件の一覧を開く。新着の一覧は先頭のドロップダウンで公開年を選び（既定は一番新しい年）、各行に公開日を月日で添える。
2. **本棚**：「本棚」と「読書履歴」の 2 タブ。
   - 本棚は自分で追加した作品だけを並べる。表紙を 3 列に並べ、表紙の下に読了率を 10 個の点で示す。
   - 「︙」メニューで表示方式（グリッド／リスト）と並べ替えを切り替える。リストでは作品名・文字遣い・著者・読了率・最後に開いた日を出す。
   - 並べ替えは「最近開いた本」（既定）・「追加日」・「タイトル」。「最近開いた本」は、まだ開いていない作品もあるため「最後に読んだ日時」と「本棚に追加した日時」の新しいほうで並べる。
   - 長押しで「書籍情報（作品詳細）」「作家情報（作家詳細）」「削除」を出す。削除しても保存済みファイルは消さない。
   - 「作家情報」は、作家が 1 人ならその作家詳細を開く。著者と翻訳者など複数いるときは、役割つきの名前（例: 吉田 甲子太郎（翻訳者））から選ばせる。
   - 読書履歴は 1 作品 1 行で、最後に開いた順に並べる。各行に読了率と最後に開いた日を出す。スワイプで削除でき、件数の上限はない。右上のごみ箱で、確かめてからすべて削除する。履歴から外しても読書位置は残る。
3. **探す**：上部の 4 タブで探す（元アプリでは「文庫」という名前だった）。
   - 分野別：NDC の第 1 次区分のカード（件数つき）→ 第 2 次区分 → 第 3 次区分 → 作品一覧。見出しは「文学 > 日本文学」のように階層を示す。作品のない区分は薄くして押せなくする。
   - 作家別：左に行の縦タブ（あ行〜わ行・その他）、右にその行の作家一覧。作家には公開中の作品数を出す。役割を問わず全員を載せる。
   - 作品別：五十音の 1 文字ずつ（あ〜ん・他）の格子 → その文字で始まる作品の番号つき一覧。
   - 児童書：分野別と同じ形で、`K` つきの作品だけを数え、たどる。
4. **その他**：直近 7 日の曜日ごとの読書時間グラフ、お気に入り作家、カラーモード（システム・ライト・ダーク。既定はシステム）、設定（読書中は画面を消灯しない・音量キーでめくる）。

## 詳細画面

- **作品詳細**：作品データ（作品名読み・分類・文字遣い種別・作品について）・底本データ・工作員データを表示し、「本棚に追加」「今すぐ読む」ボタンを置く。作家名は役割を問わず 1 人ずつ並べ、押した作家の作家詳細を開く。
- **作家詳細**：読み・ローマ字・生年・没年・人物について（長いときは「もっと」で開く）と、作品一覧を表示する。作品一覧は役割で分けず、文字遣い種別を添える。右上の ☆ でお気に入り作家をオン・オフする。

## リーダー

- WebView と CSS 段組みで縦書きを表示し、ページ単位でめくる（ADR-0001）。
- 下部バーは目次・夜間・背景・文字と、章内の進捗バー。
- 文字パネルの設定（文字サイズ・余白・行間・めくり方［スライド／なし］）は全作品で共通。フォントは同梱せず、端末の明朝体（serif）で表示する。
- 夜間はオンの間だけ背景を上書きし、オフで元の背景に戻る。カラーモードとは独立。
- 目次には大・中・小見出しをすべて並べ、タップでその位置へ飛ぶ。
- 操作：左側タップまたは右へのスワイプ（紙の本のようにページを右へ送る）で次のページ、右側タップまたは左へのスワイプで前のページ、中央タップでバーの表示・非表示。進捗バーは左端が最初のページで、読み進めると右へ伸びる。音量キーは下で次、上で前のページ。
- 読書位置は自動で保存する。読書時間はリーダーが前面にある間だけ数え、5 分間めくりがなければ計測を止める。

## 後回しにするもの

元アプリにはあるが、最初は作らない。

- 月別・年別のランキング
- リーダーの輝度調整と画像の背景テーマ
- フォントの同梱と切り替え（元アプリは IPA 明朝・しっぽり明朝・マメロン・K ゴシックを選べた）。同梱するとアプリが数 MB 大きくなるので、端末の明朝体の見た目に不満が出たときに改めて決める
- 設定の「ブックカバー」

## 作らないもの

横書き、スクロール表示、手動のしおり、作品単位のお気に入り、通知、分析データの収集、広告。
