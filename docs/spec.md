# 青空猫 仕様

設計の議論（2026-10-18）で確定した内容。用語の定義は [CONTEXT.md](../CONTEXT.md)、縦書きの描画方式は [ADR-0001](adr/0001-webview-vertical-rendering.md) を参照。

## 目的と前提

- 配信停止した「青空読書」(me.hatasei.bunko) の代わりに、自分で使うアプリを作る。使用感は元アプリに寄せる。
- ソースは GitHub で公開する。元アプリのコードは流用しない。
- Kotlin + Jetpack Compose。minSdk 31、targetSdk は最新。
- 配布は GitHub Actions で署名済み APK を作り、Releases に置く。`v*` タグの push でビルドする。署名鍵は GitHub Secrets に置く。

## データ

- カタログは青空文庫公式の作品一覧 CSV（`list_person_all_extended_utf8.zip`）から作り、端末内の DB に入れる。初回起動時にダウンロードし、以後は手動の更新ボタンで取り直す。自動更新はしない。
- 作品を開いた時点で、XHTML と挿絵を端末に自動保存する。本棚への追加とは関係しない。
- ランキングは公式の 2022 年通年（XHTML 版）を固定で使う。年月の切り替えは作らない。
- 元アプリからのデータ移行はしない。バックアップは Android 標準の自動バックアップに任せる。

## 画面（下部 4 タブ）

1. **ホーム**：上部に検索バー（作家名・作品名。読みでも引ける）。新着作品とランキングを数件ずつ表示し、「もっと見る」で全件の一覧を開く。
2. **本棚**：「本棚」と「読書履歴」の 2 タブ。
   - 本棚は自分で追加した作品だけを、最後に読んだ順に並べる。まだ開いていない作品もあるため、並び順は「最後に読んだ日時」と「本棚に追加した日時」の新しいほうで決める。長押しメニューで削除（保存済みファイルは消さない）。
   - 読書履歴は 1 作品 1 行で、最後に開いた順に並べる。スワイプで削除でき、件数の上限はない。
3. **文庫**：分野別（NDC 第 1・第 2 階層）、作家別（五十音）、作品別（五十音）、児童書（`K` つきの作品を作品名の五十音で）。
   - 作家の一覧には、著者・翻訳者などの役割を問わず全員を載せる。
4. **その他**：直近 7 日の曜日ごとの読書時間グラフ、お気に入り作家、カラーモード（ライト／ダーク）、設定（読書中は画面を消灯しない・音量キーでめくる・フォント）。

## 詳細画面

- **作品詳細**：作品データ・底本データ・工作員データを表示し、「本棚に追加」「今すぐ読む」ボタンを置く。
- **作家詳細**：作品一覧を役割（著作・翻訳など）ごとに見出しで分けて表示し、お気に入り作家をオン・オフする。

## リーダー

- WebView と CSS 段組みで縦書きを表示し、ページ単位でめくる（ADR-0001）。
- 下部バーは目次・夜間・背景・文字と、章内の進捗バー。
- 文字パネルの設定（文字サイズ・フォント・余白・行間・めくり方［スライド／なし］）は全作品で共通。フォントは明朝体を 1 つ同梱する。その他画面のフォント設定と同じ値を指す。
- 夜間はオンの間だけ背景を上書きし、オフで元の背景に戻る。カラーモードとは独立。
- 目次には大・中・小見出しをすべて並べ、タップでその位置へ飛ぶ。
- 操作：左側タップまたは左スワイプで次のページ、右側タップで前のページ、中央タップでバーの表示・非表示。音量キーは下で次、上で前のページ。
- 読書位置は自動で保存する。読書時間はリーダーが前面にある間だけ数え、5 分間めくりがなければ計測を止める。

## 作らないもの

横書き、スクロール表示、手動のしおり、作品単位のお気に入り、通知、分析データの収集、広告。
